1. **EKS Infrastructure Deployment + Parallel Workflows** — M&M Checkpoint 1 (ends 4/27), 2 sprints, IN PROGRESS
   Deploy EKS infrastructure to production and staging environments AND configure parallel development workflows. Critical path for multiplayer readiness. Enables concurrent development streams.

2. **UI Framework V2 - UI Support (Cross-Pod)** — M&M Checkpoint 1 (ends 4/27), 2 sprints, IN PROGRESS
   UI framework enhancements to support cross-pod UI needs for beta. Focused on unblocking other pods with shared UI components.

3. **Build Pipeline Review** — M&M Checkpoint 2 (4/28-5/25), 2 sprints, NOT STARTED
   Audit and optimize build pipeline for efficiency, maintainability, and scalability. Clean up redundant workflows, improve error reporting, ensure pipelines are well-documented.

4. **Compliance (OneTrust, Age Gate)** — M&M Checkpoint 2 (4/28-5/25), 2 sprints, NOT STARTED
   Implement compliance requirements for beta launch: OneTrust integration for privacy/consent management, proper age gating, compliance with legal requirements.

5. **UI Framework V2 (Full)** — M&M Checkpoint 2 (4/28-5/25), 2 sprints, NOT STARTED
   Complete UI framework implementation and legacy UI migration. Completes the full framework architecture.

6. **Audio Tooling Foundation** — M&M Checkpoint 3 (5/26-6/22), TBD, NOT STARTED **[STRETCH GOAL]**
   Audio pipeline must be established for content production. Enables audio team to scale content creation for beta.

7. **QA Automation** — M&M Checkpoint 3 (5/26-6/22), TBD, NOT STARTED **[STRETCH GOAL]**
   Automated testing pipeline to validate game quality. Includes automated end-to-end testing and performance validation.

8. **Performance/Optimization and Review** — M&Ms (ongoing all checkpoints), Ongoing, IN PROGRESS
   Continuous performance monitoring, optimization, memory profiling, and infrastructure improvements. Game performance meets beta quality bar.
