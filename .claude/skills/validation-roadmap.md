# Validation Roadmap Skill

Generate and maintain the Lotus Validation Roadmap visual dashboard on the production website.

## Purpose

This skill:
1. Fetches validation roadmap data from Notion (Winning Hypotheses → BHQs → SHQs)
2. Generates an interactive HTML dashboard at `generated/dashboard/validation_roadmap.html`
3. Serves as the source of truth for questions about SHQ/BHQ targeting by milestone
4. Keeps the dashboard in sync with the latest Notion data

## Data Source

**Notion Page:** [Lotus Validation Roadmap](https://www.notion.so/1d73f0b3b6ab80f4a18fd58479aa8da2)
**Data Source ID:** `collection://4b7e078b-4c09-4f7c-b7ff-7c1fe2db0a21`

## Data Structure

The roadmap follows a hierarchical structure:

```
Winning Hypotheses (3)
├── Battle Hypothesis
│   ├── BHQ 1: Question text...
│   │   ├── SHQ 01: Question text... [Milestone] [Confidence]
│   │   └── SHQ 02: Question text... [Milestone] [Confidence]
│   └── BHQ 2: Question text...
│       └── SHQ 03: Question text... [Milestone] [Confidence]
├── Empire Hypothesis
│   └── BHQ 3: Question text...
│       └── SHQ 04: Question text... [Milestone] [Confidence]
└── Monetization Hypothesis
    └── BHQ 4: Question text...
        └── SHQ 05: Question text... [Milestone] [Confidence]
```

**Properties:**
- `Hypothesis`: Battle Hypothesis, Empire Hypothesis, Monetization Hypothesis, Production Hypothesis
- `BHQ`: Big Hypothesis Question (text)
- `SHQ`: Sub-Hypothesis Question (title field)
- `Milestone`: Core Loop, Systems Validation, Early Experience, Multiplayer & Meta, Live Ops, Fortis Soft Launch
- `Confidence`: 🟢 Confident we have it solved, 🟡 On track - Additional iterations required, 🔴 Off Track - need to do something, 🟣 Validation Pending, Reword/Moved to next milestone
- `ClickUp`: URL to related ClickUp task
- `Details (optional)`: Additional context

## Execution Steps

### 1. Fetch Roadmap Page Structure

Use `notion-fetch` to get the main roadmap page:
- URL: `https://www.notion.so/1d73f0b3b6ab80f4a18fd58479aa8da2`
- Extract: Winning Hypothesis text for each hypothesis, milestone details

### 2. Query All SHQ Data

Use `notion-query-data-sources` to fetch all SHQ entries:

```sql
SELECT 
  Hypothesis, 
  BHQ, 
  SHQ, 
  Milestone, 
  Confidence, 
  ClickUp, 
  "Details (optional)" as Details,
  url
FROM "collection://4b7e078b-4c09-4f7c-b7ff-7c1fe2db0a21"
ORDER BY Hypothesis, BHQ, SHQ
```

### 3. Structure Data for Dashboard

Organize the query results into a hierarchical JSON structure:

```javascript
{
  "generated_at": "ISO timestamp",
  "milestones": [
    {
      "name": "Multiplayer & Meta",
      "status": "current",
      "start_date": "2026-04",
      "end_date": "2026-06",
      "total_shqs": 15,
      "by_confidence": {
        "confident": 2,
        "on_track": 5,
        "off_track": 1,
        "validation_pending": 7
      }
    }
  ],
  "winning_hypotheses": [
    {
      "id": "WH1",
      "name": "Battle",
      "statement": "We think we can win at every point...",
      "bhqs": [
        {
          "id": "BHQ 1",
          "question": "Question text...",
          "shqs": [
            {
              "id": "SHQ 01",
              "question": "Question text...",
              "milestone": "Multiplayer & Meta",
              "confidence": "🟡 On track - Additional iterations required",
              "clickup_url": "https://...",
              "details": "...",
              "notion_url": "https://..."
            }
          ]
        }
      ]
    }
  ]
}
```

### 4. Generate Data File

Create `generated/dashboard/validation_roadmap_data.js` with a JavaScript const pattern (matching other dashboard data files):

```javascript
// generated/dashboard/validation_roadmap_data.js
// Auto-generated by /validation-roadmap — do not edit manually
// Generated: YYYY-MM-DDTHH:MM:SSZ

const VALIDATION_ROADMAP_DATA = {
  "generated_at": "ISO timestamp",
  "notion_source": "https://www.notion.so/1d73f0b3b6ab80f4a18fd58479aa8da2",
  "data_source_id": "collection://4b7e078b-4c09-4f7c-b7ff-7c1fe2db0a21",
  "milestones": [...],  // Array of milestone objects
  "winning_hypotheses": [...]  // Array of winning hypothesis objects with BHQs and SHQs
};
```

**Important:** `milestones` MUST be an array, not an object. Each milestone object in the array should have the structure shown in step 3.

This file is loaded by the static HTML template at `generated/dashboard/validation_roadmap.html` via a `<script>` tag.

### 5. Output Summary

Log to console:
- Number of milestones, BHQs, SHQs processed
- Data file location and timestamp
- Any warnings or issues encountered

**Note:** The HTML template (`validation_roadmap.html`) is a static file maintained separately. Only the data file is regenerated by this skill.

## Output Files

- `generated/dashboard/validation_roadmap.html` - Static HTML template (maintained separately, not generated by skill)
- `generated/dashboard/validation_roadmap_data.js` - Dynamic data file (generated by skill)
- Console output: Summary statistics (number of milestones, BHQs, SHQs processed)

## Answering Questions

When the user asks questions about the validation roadmap:

**Example Questions:**
- "What SHQs are we targeting for Multiplayer & Meta milestone?"
- "Which BHQs does SHQ 17 belong to?"
- "What's the confidence level on Battle hypothesis?"
- "How many SHQs are off track?"

**Approach:**
1. Query the Notion data source with appropriate filters
2. Structure the answer clearly showing:
   - Milestone name
   - Winning Hypothesis → BHQ → SHQ hierarchy
   - Confidence levels
   - Links to Notion/ClickUp
3. Provide counts and summaries as appropriate

**Example SQL for milestone filtering:**
```sql
SELECT Hypothesis, BHQ, SHQ, Confidence 
FROM "collection://4b7e078b-4c09-4f7c-b7ff-7c1fe2db0a21"
WHERE Milestone = 'Multiplayer & Meta'
ORDER BY Hypothesis, BHQ
```

## Dashboard Features

The HTML dashboard should include:

1. **Milestone Selector Tabs**
   - Current milestone highlighted
   - Click to switch between milestones
   - Show completion percentage per milestone

2. **Winning Hypothesis Cards**
   - Battle (red theme)
   - Empire (blue theme)
   - Monetization (yellow theme)
   - Production (gray theme)
   - Each shows overall confidence trend

3. **BHQ Sections**
   - Collapsible sections per BHQ
   - Progress indicator (X/Y SHQs answered)
   - SHQ list with confidence badges

4. **Filters & Search**
   - Filter by confidence level
   - Filter by hypothesis
   - Search SHQ text

5. **Summary Statistics**
   - Total SHQs per milestone
   - Confidence distribution
   - Time to next milestone

Display a warning if the dashboard data is >7 days old, similar to the production dashboard.

- ClickUp links are optional; display "—" if not set
